📦 Inventory CLI

A simple command-line tool to manage hardware and software stock.
What it does

    Interactive Menu: Run the program once and navigate through options.

    Add Products: Add new items (Hardware or Software) during the session.

    Search & Edit: Find items by name and update their price or stock on the fly.

    Filter: View items by specific categories like "Laptops" or "Software".

    Formatted View: See your entire stock in a clean, organized list.


Installation & Setup

    Clone the project:

    git clone https://github.com/L3r0yyy/CLI-Inventory-System.git
    cd  CLI-Inventory-System


Install dependencies: 
    
    (Make sure you have Composer installed on your machine)
     
    composer install

Run the app:

    php inventory.php
